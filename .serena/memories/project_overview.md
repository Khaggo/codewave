AUTOCARE is a Windows monorepo for Cruisers Crib Auto Care Center. Runtime applications are: `backend/apps/main-service` (NestJS, port 3000), `backend/apps/ecommerce-service` (NestJS, port 3001), `frontend/` (full Next.js staff and super-admin portal, port 3002), and `mobile/` (Expo/React Native customer app, Metro 8081 and optional Expo web 8090). PostgreSQL is the system of record, Drizzle is the ORM, and REST/OpenAPI is the synchronous contract. Canonical architecture truth lives under `docs/architecture`; engineering status and QA evidence live under `docs/project-control`; execution tasks live under `docs/architecture/tasks`; integration contracts live under `docs/contracts`. Technicians are operational profiles in the intended workflow rather than ordinary staff-web login owners. As of 2026-07-26, backend production config fails closed on weak secrets/OTP bypass/CORS/database settings, both services use Helmet and throttling, OTP attempts are bounded and atomic, and upload storage validates file signatures and path containment. Root, frontend, and backend production npm audits are clean; Expo SDK 54 retains 18 high and 9 moderate transitive advisories pending a dedicated Expo 57/React Native 0.86 migration.
