Use the smallest relevant checks first, then broaden with risk. Backend changes: run focused Jest tests, then typecheck and build; use the serial suite for shared, security, or cross-module changes. Architecture docs: run `npm run check:docs` and refresh validator-owned hashes in `docs/architecture/agent-manifest.json` for changed canonical files. Frontend changes: run `npm run test:web` and `npm run build:web`. Mobile changes: run `npm run test:mobile`, then an Android Expo export for bundling changes. API changes: run `npm run contracts:check` and compare the committed OpenAPI document with DTOs and clients. Runtime ports are main API 3000, staff web 3002, Storybook 6006, Expo LAN 8081, and Expo web 8090. Always use bounded runtime-manager commands. Preserve unrelated dirty-worktree changes.
