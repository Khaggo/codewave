# Documentation Archive

This directory stores completed plans, dated QA reports, and superseded implementation notes.
Archived documents remain searchable and preserve Git history, but they are not business or
architecture authority.

Before archiving a document:

1. Move any still-current rule into `docs/architecture/`.
2. Add a short banner linking to the canonical replacement.
3. Update inbound links where the old document was used as current guidance.
4. Keep active and ready work in `docs/architecture/tasks/`; archive completed narrative reports.

Do not archive domain contracts, RBAC/security policy, API strategy, DTO policy, or the repository
map.
